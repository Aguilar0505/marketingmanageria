# Marketing Manager AI

Prompt para LOVABLE - Landing Pages Proyectos Practicantes Merkatics

Por favor, actúa como un Desarrollador Frontend Senior especializado en React, TypeScript, Tailwind CSS, diseño UX/UI, optimización de conversiones, SEO técnico y posicionamiento para motores de búsqueda e inteligencia artificial.

Necesito desarrollar una landing page moderna, estructurada y modular, creada con Vite, React, TypeScript y Tailwind CSS.

La landing page debe estar orientada a la conversión, tener una apariencia profesional de alto impacto, cargar rápidamente, funcionar perfectamente en dispositivos móviles y estar optimizada para Google, Bing y motores de respuesta basados en inteligencia artificial.

2. Objetivo estratégico

Construye una landing page de alta conversión que comunique claramente:

Qué problema tiene el visitante.

Qué solución ofrece la marca.

Cuáles son sus beneficios principales.

Por qué la propuesta es diferente y confiable.

Qué debe hacer el visitante como siguiente paso.

La página debe guiar al usuario hacia una acción principal, eliminando distracciones y reduciendo la fricción. El CTA principal debe aparecer estratégicamente en:

Hero principal.

Después de la presentación de beneficios.

Después de la prueba social.

Antes o dentro del cierre final.

Mantén una sola acción principal en toda la página. Si existe una acción secundaria, debe tener menor jerarquía visual.

3. Dirección visual

Diseña una experiencia de alto impacto, contemporánea, elegante y profesional. La apariencia debe incluir:

Hero visualmente contundente.

Jerarquía tipográfica clara.

Espaciado generoso y composición ordenada.

Contraste suficiente para facilitar la lectura.

Tarjetas modernas para beneficios, soluciones o servicios.

Uso estratégico de fotografías y recursos visuales.

Botones de CTA visibles y consistentes.

Elementos de confianza y prueba social.

Microinteracciones discretas.

Animaciones suaves al hacer scroll (fade-in).

Estados hover y focus correctamente diseñados.

Diseño completamente responsive.

Excelente presentación en celular, tableta y escritorio.

Evita:

Diseños genéricos o con apariencia de plantilla.

Uso excesivo de degradados.

Animaciones que distraigan.

Carruseles innecesarios.

Textos difíciles de leer sobre imágenes.

Botones sin una acción real.

Imágenes genéricas si ya se proporcionaron recursos oficiales.

Secciones decorativas que no ayuden a la conversión.

Menús extensos que permitan abandonar la landing page.

Utiliza los colores, tipografías y estilo visual de la marca.
